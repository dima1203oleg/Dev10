# DATA PROVENANCE SPECIFICATION

**Project:** TenderAI OS (dima1203oleg/Dev10)  
**Principle of Truth:** **Every data element must trace back to a verified origin.**

---

## 1. External Data Origin: Prozorro Live Integration

The system enforces strict lineage for all Prozorro data. No artificial fallback or static mockup models are injected.

### 1.1. Lineage Fields Saved in Database
Every retrieved Prozorro record maintains the following metadata structure:
- **`source`**: The official register name (`"PROZORRO_REST_API"`).
- **`sourceUrl`**: The unique endpoint URI where the raw payload was fetched (e.g., `https://public.api.openprocurement.org/api/2.5/tenders/tender_id`).
- **`sourceRecordId`**: The Prozorro internal ID.
- **`retrievedAt`**: ISO timestamp marking ingestion time.
- **`sourceVersion`**: Version header received from Prozorro.
- **`hash`**: SHA-256 integrity hash of the raw JSON payload.

### 1.2. Ingestion Pipeline
```
Prozorro Public API ──> REST Fetcher ──> Payload Hash Integrity ──> Normalizer ──> DB (Drizzle PostgreSQL)
```

---

## 2. AI Inference Provenance

Every automated assessment, score, or recommendation generated by Gemini includes the tracking structure:
- **`model`**: Identifies model used (e.g., `"gemini-1.5-flash"` or `"gemini-2.0-flash"`).
- **`modelVersion`**: Model build or release version.
- **`promptVersion`**: Internal tracking ID of the prompt template used.
- **`inputHash`**: SHA-256 hash of the input context submitted to the model.
- **`evidenceIds`**: List of source records, pages, or legal quotes used by the model for grounding.
- **`generatedAt`**: Ingest timestamp.

---

## 3. Legal Source Registry

To support Section 24 (Legal Engine) and Section 81 (Source Links), legal quotes or AMCU pre-submission checks are matched to the Legal Source Registry:
- **`lawSource`**: Law Name (e.g., `"Закон України 'Про публічні закупівлі'"`).
- **`article`**: Law Article (e.g., `"Стаття 16"`).
- **`paragraph`**: Section or part numbering.
- **`effectiveDate`**: Valid effective date range.
- **`sourceUrl`**: Verification URL to the Verkhovna Rada portal (`https://zakon.rada.gov.ua/...`).
- **`exactQuote`**: Exact text matched from the legislation or AMCU precedent database.

Every decision report in the TenderAI interface displays a clickable `[Джерело]` link resolving to these certified records.
